# Personal Portfolio Website

## Project Overview
This is a personal portfolio website developed using HTML and CSS. It consists of two main pages: a Portfolio page and a Contact page.

## Code Structure

### 1. HTML
- Defines the basic structure and content of the website.
- Creates the Portfolio page to display personal information, skills, and projects.
- Creates the Contact page to display contact details and communication information.
- Uses HTML elements such as headings, paragraphs, links, images, and sections to organize the content.

### 2. CSS
- Controls the overall appearance and styling of the website.
- Defines colors, fonts, spacing, margins, and layouts.
- Styles navigation links, buttons, sections, and other page elements.
- Improves the visual presentation and consistency across both pages.

## Technologies Used
- HTML5
- CSS3

## Pages
- **Portfolio Page:** Displays personal details, skills, and project information.
- **Contact Page:** Provides contact information and ways to connect.

## Purpose
The main objective of this project is to demonstrate fundamental knowledge of HTML and CSS by creating a structured and visually appealing personal portfolio website.
